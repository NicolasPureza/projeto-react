# Atividade Prática — Desenvolvimento e Deploy com React, GitHub e Vercel

**Instituição:** SENAI  
**Foco:** Criação de aplicação em React, controle de versão com Git/GitHub e hospedagem contínua na Vercel.

---

## 📌 Visão Geral da Atividade

Desenvolver uma aplicação React utilizando o Visual Studio Code (VS Code) como ambiente de desenvolvimento. Em seguida, utilizar o Git para versionar o projeto e realizar o commit e push para um repositório no GitHub. Após publicar o código no GitHub, realizar o deploy da aplicação na Vercel, conectando o repositório para que a plataforma possa realizar a publicação automática do projeto. Ao final, o projeto deverá estar disponível online por meio de uma URL pública da Vercel.
